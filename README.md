# AmmarAI Launchpad

AmmarAI — Complete SEO-Driven AI Platform Website & Frontend



Design and build a world-class, premium, modern, SEO-focused marketing website for AmmarAI.



The website should position AmmarAI as a comprehensive AI creation and productivity platform, not simply an AI content generator.



---



🚨 CRITICAL PROJECT SCOPE



This project is FRONTEND MARKETING WEBSITE ONLY.



Do NOT build or create:



- Backend

- Database

- APIs

- Authentication

- Login system

- User accounts

- Dashboard/application

- Billing/payment system

- AI model integrations

- Server-side functionality

- Admin panel

- User management

- Data storage

- Supabase

- Firebase

- Any replacement backend infrastructure



The existing AmmarAI product infrastructure is outside the scope of this project.



The goal is to create the public-facing website, landing pages, feature pages, tool pages, SEO content, navigation, visual design, and conversion experience.



Buttons such as "Start Free", "Login", and "Try Now" may link to placeholder URLs or existing destinations, but they do not need functional application logic.

14. CONTENT REQUIREMENTS FOR EVERY SEO PAGE



This is extremely important.



Do NOT create thin SEO pages.



Every important SEO landing page should contain meaningful content appropriate to the search intent.



A strong page structure should generally include:



Hero



Clear H1.



Short explanation.



Primary CTA.



Relevant visual.



What is [Tool]?



Explain the concept clearly.



What can you do with [Tool]?



Explain practical applications.



How [Tool] works



Provide a simple step-by-step explanation.



Examples



Show realistic example inputs and outputs.



Key capabilities



Explain important functionality.



Benefits



Explain why someone would use it.



Who is it for?



Identify relevant audiences.



Practical use cases



Give concrete workflows.



Tips / Best Practices



Provide genuinely helpful advice.



Common mistakes



Explain mistakes users should avoid.



Related tools



Link naturally to other AmmarAI tools.



FAQ



Answer real search-intent questions.



CTA



Encourage visitors to try AmmarAI.



The exact structure should vary depending on the topic so pages don't become repetitive.



---



15. CONTENT DEPTH



Content should be comprehensive without being artificially long.



Do not add paragraphs simply to increase word count.



The goal is:



Search intent + usefulness + expertise + clarity + conversion.



A typical major feature/tool page should contain enough substantive information to fully answer the visitor's questions.



For major commercial pages, aim for approximately:



1,200–2,500+ words when the topic genuinely warrants it.



For narrower tools, use less content when appropriate.



Do not force every page to reach the same word count.



Quality is more important than word count.
